CSV format guide

Follow these rules when preparing a bulk import file. The format is inspired by common exam-platform conventions (e.g. Moodle CSV question import): one row per question, a header row, and UTF-8 encoding.

File type Save as .csv in UTF-8. Do not upload Excel (.xlsx) files.
Header row The first line must list column names exactly as shown below.
One question per row Each line after the header is a single question.
Commas in text Wrap any field that contains commas in double quotes, e.g. "What is 2+2?"
Question types mcq, true_false, or short_answer (aliases like tf also work).

Columns

Column Required Description
typeYesmcq, true_false, or short_answer
textYesQuestion stem / prompt
correctYesMCQ: option key (A–F) or matching option text · T/F: true or false · Short: reference answer
marksYesPositive whole number (points)
option_a … option_fMCQ onlyAt least two options for multiple choice
explanationNoFeedback shown after grading (if enabled)
sectionNoOutline label, e.g. Section A: Multiple Choice
difficultyNoeasy, medium, or hard
blooms_levelNoe.g. Remember, Apply, Analyze
tagsNoComma-separated module tags (quote the cell if tags contain commas)
